# Controller setup

*[中文版](zh/controller-setup.md)*

One-time setup for the ROBOGUIDE virtual controller, done in order:

1. [Prerequisites](controller-setup/prerequisites.md): controller options to confirm, what the two servers are for
2. [Server tags](controller-setup/server-tags.md): S8 always needed, S7 depending on your use case
3. [Loading the driver](controller-setup/loading-the-driver.md): dropping the files in `driver/upload/` onto the controller
4. [Running it](controller-setup/running.md): starting MAPPDK
5. [Verifying](controller-setup/verifying.md): confirming it actually connects, and where to look when something's wrong

Walk through this in order the first time; after that, only step 4
needs repeating on every boot.
