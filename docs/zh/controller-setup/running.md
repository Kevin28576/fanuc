# 執行

MAPPDK 是常駐 server，要一直跑著，不要在 T2 模式跑。T2 要全程按住
SHIFT，手一放程式就中止，TP 會跳出 `PROG-048 运行时放开了[Shift]键`。

## 啟動步驟

1. `辅助` → `中止程序`，清掉殘留的 `已暂停`
2. `RESET` 清除異常
3. 模式切 **AUTO**，TP 切 **OFF**
4. `一览` → 選 `MAPPDK` → 按面板上的綠色 **CYCLE START**

`MAPPDK` 裡面就兩行：

```
1: RUN MAPPDK_SERVER
2: RUN MAPPDK_LOGGER
```

只用 S8 的話，把第 2 行刪掉，[server tag 設定](server-tags.md) 那邊也就
不用設 S7。

啟動成功的話，TP 畫面會出現 `MAPPDK SERVER started.`，狀態變 `执行中`。

## 想要開機自動啟動？試過，放棄了

想過讓 MAPPDK 開機自動執行，不用每次手動 CYCLE START。試了兩條路都
不行：

- **背景任務**（`菜单` → `背景执行` 那個 1-8 號 slot 的畫面）：MAPPDK
  放進去會報 `INTP-665 程序的背景执行不能`，這支程式不能用背景方式跑。
- **`设置` → `选择程序`**（`程序选择模式`/`自动运行开始方法`）：摸過
  三層，這整頁其實是「外部 PLC/UOP 訊號控制程式選擇跟啟動」的設定，
  跟「開機自動執行某支程式」是兩回事，別浪費時間在這頁找。這兩項
  維持預設的 `其他` 就好，不要改成 `UOP`（除非真的接了 PLC）。

有沒有其他畫面能做到開機自動執行，沒有查證出來，需要 FANUC 官方
手冊或原廠支援才能確定。目前維持手動 `CYCLE START`，穩定、零風險，
代價只是開機後多花幾秒鐘按一下。

啟動後，繼續看[驗證](verifying.md)確認真的連得上。
