# 控制器端設定

*[English](../controller-setup.md)*

ROBOGUIDE 虛擬控制器的一次性設定，按順序做：

1. [開始之前](controller-setup/prerequisites.md)：確認控制器選項、兩支 server 的用途
2. [設定 server tag](controller-setup/server-tags.md)：S8 一定要設，S7 視情況
3. [載入 driver](controller-setup/loading-the-driver.md)：把 `driver/upload/` 的檔案丟進控制器
4. [執行](controller-setup/running.md)：啟動 MAPPDK
5. [驗證](controller-setup/verifying.md)：確認連得上、出問題時查這裡

第一次設定照順序走一遍就好，之後開機只要重複第 4 步。
